# Chrome Extensions Audit Plan

## 目標

在既有 `chrome-settings-collector.ps1` 的基礎上，補上 Chrome 外掛清單蒐集與匯出能力，用來判斷是否有安裝可能影響網站資料、隱私或儲存行為的擴充套件。

- [x] 確認外掛資料來源，因為 Chrome 外掛資訊分散在 `Extensions` 目錄與 Profile 設定檔，先確認來源才能正確抓到名稱、版本與啟用狀態。
- [x] 擴充摘要輸出，因為除了既有設定摘要，也要把每個 Profile 的外掛數量與外掛明細整理出來，方便直接檢視。
- [x] 擴充匯出內容，因為 `summary.json` 與 `summary.txt` 都需要包含外掛資訊，後續才能保存與比對。
- [x] 驗證腳本輸出，因為新增外掛掃描後，仍要確保原本的設定檢查與匯出功能正常。

## 預計輸出

- 每個 Profile 的外掛總數
- 每個外掛的 ID、名稱、版本、是否啟用、安裝路徑
- 可取得時一併輸出 `manifest` 權限與描述

## 注意事項

- 只讀取本機設定與外掛檔案，不修改 Chrome
- 外掛名稱若使用語系 key，可能會先保留原值，後續再評估是否解析 `_locales`
- 已依使用者「全自動」指示完成實作與驗證
