# Chrome Settings Audit Plan

## 目標

建立一個可在 Windows 上執行的腳本，用來：

- [x] 確認 Chrome 使用中的設定來源與可讀取範圍，因為 Chrome 可能有多個 Profile，且設定分散在 `Local State` 與各 Profile 的 `Preferences`，先釐清來源才能避免判讀錯誤。
- [x] 實作「設定檢查」功能，因為需要先把與隱私、站點資料、背景執行、內容設定等可能影響網站資料保存的欄位整理成摘要，才能快速判斷風險。
- [x] 實作「設定匯出」功能，因為除了螢幕輸出，也需要把原始設定與整理後的摘要輸出到檔案，方便保存與比對。
- [x] 補充使用方式與限制說明，因為有些 Chrome 設定不一定存在、不同版本欄位可能不同，必須清楚說明腳本讀到的是什麼。

## 預計輸出

- 讀取 Chrome `User Data` 目錄下的 `Local State`
- 列出可用 Profile 與其 `Preferences`
- 摘要輸出與網站資料保存相關的設定
- 匯出成 JSON 檔，必要時再加上人類可讀的摘要檔

## 注意事項

- 只讀取與匯出設定，不修改 Chrome 設定
- 先以目前使用者的本機 Chrome 安裝路徑為主
- 已依使用者「全自動」指示完成實作與驗證
