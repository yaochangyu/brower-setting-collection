# Collector Launcher Plan

## 目標

新增一支 PowerShell 啟動腳本，先從 GitHub 下載最新的 `chrome-settings-collector.ps1`，再把接收到的參數原樣轉交給它執行，讓使用者不需要先手動下載主腳本。

## 實作方式

- blob 頁面網址不能直接拿來當腳本內容下載，實作時會改用對應的 raw URL。
- 下載腳本會負責建立暫存資料夾、下載檔案、解除封鎖，最後呼叫 `chrome-settings-collector.ps1`。
- 參數設計會盡量對齊既有主腳本，避免使用方式不一致。
